Python File Organizer

Overview

A simple Python automation project that organizes files into separate folders based on their file extensions.

Features

• Scans files in a selected directory
• Creates destination folders automatically
• Identifies files based on their extensions
• Moves files into their corresponding folders
• Uses the os and shutil modules for file management

File Organization

CSV files → Excel Files
PDF files → Pdf Files
JPG files → Wallpaper Files
DOCX files → Word Files

Technologies Used

Python
OS Module
Shutil Module

How It Works

The program scans the selected directory and checks the extension of each file. It creates the required folders if they do not already exist and automatically moves each file into its corresponding folder.

Python Concepts Used

• File and directory handling
• os.listdir()
• os.path.exists()
• os.makedirs()
• shutil.move()
• For loops
• Conditional statements
• String operations

Project Purpose

This project was created to practice Python file handling and demonstrate how simple automation can be used to organize files efficiently.
